## Choose an interface

| Interface | Entry point | Authentication |
| --- | --- | --- |
| REST API | `https://truckerfetch.com/api/v1` | Scoped API key in a bearer header |
| Hosted MCP | `https://truckerfetch.com/api/mcp` | OAuth through your MCP client |
| Agent skill | [Official skill repository](https://github.com/truckerfetch/truckerfetch-agent-skills) | Your configured REST or MCP credentials |

All data API routes and hosted MCP operations require active Pro access and the appropriate scopes. Public documentation and the [OpenAPI contract](https://truckerfetch.com/api/v1/openapi.json) do not require a key.

## Start with published evidence

Carrier Census status, operating authority and observed insurance filings describe different facts. Keep their source dates and evidence with your results. A filing anniversary is not a verified policy expiration, and a first observation is not a newly formed business.

Read [data quality](/data-quality) before using results for qualification or outreach. The API follows the same account permissions and suppressions as your dashboard.
